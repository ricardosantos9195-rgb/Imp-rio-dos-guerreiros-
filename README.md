# Império dos Guerreiros

Protótipo Android de estratégia medieval com guerras entre alianças.

## APK

Abra **Actions → Criar APK**, aguarde a compilação e descarregue o ficheiro **Imperio-dos-Guerreiros-APK**.

## Conteúdo atual

- Cidade medieval interativa
- Recursos e evolução de poder
- Infantaria, cavalaria, arqueiros e máquinas de cerco
- Aliança Guerreiros XS
- Mapa de fortalezas e batalhas
- Progresso guardado no dispositivo
